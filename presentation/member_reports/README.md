# Member Report Logs

Each team member (and the agent acting on their behalf) keeps a **report log** here documenting
what they did and the challenges they faced. These are the raw source material Hessam later
collects to produce the **group report** and the **presentation slide deck** — so they should be
specific, honest about difficulties, and quote real numbers/metrics wherever possible.

- One file per member: `rolando_report_log.md`, `diana_report_log.md`, `jordan_report_log.md`,
  `damir_report_log.md`, `hessam_report_log.md`.
- Follow `_TEMPLATE.md`. Fill it in as you work (not only at the end) so nothing is lost if a
  session is interrupted.
- Write for a reader who wasn't there: explain the *why* behind decisions, and describe each
  challenge + how it was (or wasn't) resolved. This is what makes the report and slides good.

Hessam's stage assembles `../slides_outline.md` and the final report from these logs plus the
metrics in `outputs/metrics/` and figures in `outputs/figures/`.
